## Regla de idioma -- OBLIGATORIA, sin excepciones

Todo el texto en español de este proyecto (interfaz, mensajes, validaciones,
correos, comentarios de UI) debe usar EXCLUSIVAMENTE la forma "tú". Nunca
voseo argentino: nada de "vos", "tenés", "podés", "decís", "hacés", "elegí",
"sos", "mostrame", "avisame", etc. Si tienes duda de cómo se conjuga algo en
"tú", usa la forma estándar de México/España/Colombia (tú tienes, tú puedes,
tú quieres, tú dices, elige, muéstrame).

Esto asegura que cualquier sesión futura de Claude Code en esta carpeta lo
lea automáticamente sin que el usuario tenga que repetirlo.
